Sign in to publish

Posts are saved straight to your GitHub repository, so you sign in with a GitHub access token. Your site redeploys automatically after each publish.

How to get a token (one time, 2 minutes)
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Name it Blog admin and pick an expiration (for example 1 year).
  3. Under Repository access, choose Only select repositories and pick this site's repository.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above. Keep it private like a password.
